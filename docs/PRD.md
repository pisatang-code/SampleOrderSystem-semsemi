# 반도체 시료 생산주문관리 시스템 PRD

### 역할별 흐름

| 역할 | 역할 설명 | 주요 업무 |
|------|-----------|-----------|
| 고객 | 시료 요청자 | 필요한 시료를 이메일로 요청 |
| 주문 담당자 | 주문서 관리 | 요청에 맞게 주문서 작성 |
| 생산 담당자 | 시료 생산·승인 | 개발 시료 등록, 주문 수신 후 승인 또는 거절 |

**흐름:** 고객 시료 요청 → 주문 담당자 주문서 작성 → 생산 담당자 승인/거절 → 주문 담당자 결과 반영

### 시스템 개요

- **운영 방식:** 콘솔(CLI) 기반으로 동작, 담당자가 직접 명령 입력
- **생산 라인:**
  - 공장에서 시료 하나를 생산하는 설비 흐름
  - 하나의 생산 라인은 시료를 하나씩 생산
  - 주문이 들어온 시료에 대해서만 생산

---

## 2. 주문 상태 흐름

모든 주문은 아래 상태 중 하나를 가진다. `REJECTED`는 거절된 주문으로 정상 흐름 외의 상태이며 모니터링에서 제외된다.

| 상태 | 의미 |
|------|------|
| `RESERVED` | 주문 접수 |
| `REJECTED` | 주문 거절 |
| `PRODUCING` | 주문 승인 완료 및 재고 부족으로 생산 중 |
| `CONFIRMED` | 주문 승인 완료 및 출고 대기 중 |
| `RELEASE` | 출고 완료 |

**상태 전이:**
```
RESERVED → (승인, 재고 충분)  → CONFIRMED → RELEASE
RESERVED → (승인, 재고 부족)  → PRODUCING → CONFIRMED → RELEASE
RESERVED → (거절)             → REJECTED
```

## 3. 기능 명세

### 3-1. 메인 메뉴

기능별 선택 화면을 표시하고, 전체 시료에 대한 요약 정보(등록 시료 수, 총 재고, 전체 주문 수, 생산라인 대기 수)를 확인할 수 있다.

| 메뉴 번호 | 메뉴명 | 의미 |
|-----------|--------|------|
| 1 | 시료 관리 | 새로운 시료 등록, 목록 조회, 이름 검색 기능 |
| 2 | 시료 주문 | 고객 주문 접수 |
| 3 | 주문 승인/거절 | 생산 라인 담당자의 승인·거절 처리 |
| 4 | 모니터링 | 상태별 주문 수 및 시료별 재고 현황 확인 |
| 5 | 생산라인 조회 | 현재 생산 중인 시료 및 대기 중인 생산 큐 확인 |
| 6 | 출고 처리 | CONFIRMED 상태 주문에 대해 출고 실행 |
| 0 | 종료 | 프로그램 종료 |

---

### 3-2. 시료 관리

시료(Sample)는 시스템의 가장 기본이 되는 단위. 각 시료는 고유한 이름과 속성을 가지며, **시스템에 등록된 시료만 주문 가능**.

#### 시료 속성

| 속성 | 설명 |
|------|------|
| 시료 ID | 시료 고유 식별자 |
| 이름 | 시료명 |
| 평균 생산시간 | 단위: min/ea |
| 수율 | 정상 시료 / 총 생산 시료 (예: 100개 중 90개 정상 → 0.9) |

#### 하위 메뉴

| 메뉴 | 의미 |
|------|------|
| 시료 등록 | 새로운 시료를 시스템에 추가 (속성 값: 시료 ID, 이름, 평균 생산시간, 수율) |
| 시료 조회 | 등록된 모든 시료 목록을 확인 (현재 재고 수량 포함) |
| 시료 검색 | 이름 등 속성으로 특정 시료를 검색 |

---

### 3-3. 시료 주문 (주문 접수)

고객이 시료를 요청하면 주문 담당자가 주문을 생성한다.

#### 시료 예약

- 고객이 원하는 시료와 수량을 주문
- 이 시점에서 주문 상태는 `RESERVED`

#### 예약 시 입력 값

| 입력 항목 | 설명 |
|-----------|------|
| 시료 ID | 주문할 시료의 ID |
| 고객명 | 주문 고객 이름 |
| 주문 수량 | 요청 수량 (ea) |

- 입력 후 내용 확인 및 예약 접수 확정
- 접수 완료 시 주문번호(예: `ORD-20260416-0043`) 및 현재 상태(`RESERVED`) 표시

---

### 3-4. 주문 승인/거절

접수된 주문(`RESERVED`) 목록을 확인하고, 특정 주문에 대해 승인 또는 거절을 처리한다.

#### 접수된 주문 목록

- `RESERVED` 상태의 주문 목록 표시 (주문번호, 고객, 시료, 수량, 상태)

#### 주문 승인

- 접수된 특정 주문에 대해 승인
- 승인 시 재고 상황에 따라 **자동으로** 2가지 방식으로 처리:
  - **재고가 충분한 경우** → 주문을 즉시 `CONFIRMED` 상태로 전환
  - **재고가 부족한 경우** → 생산 라인에 자동으로 등록, 주문 상태를 `PRODUCING`으로 전환

#### 주문 거절

- 접수된 특정 주문에 대해 거절
- 즉시 `REJECTED` 상태로 전환

---

### 3-5. 모니터링

주문에 따른 시료 재고 정보를 모니터링하는 기능. 담당자가 현재 시스템 상태를 한눈에 파악할 수 있도록 구성.

#### 주문량 확인

- 현재 상태별(`RESERVED` / `CONFIRMED` / `PRODUCING` / `RELEASE`) 주문 목록 및 건수를 확인
- `REJECTED`는 유효한 주문이 아니므로 제외

#### 재고량 확인

- 각 시료별 현재 재고 수량 확인
- 주문 대비 재고 수량에 따라 상태 표기:

| 상태 | 설명 |
|------|------|
| 여유 | 주문 대비 재고 충분 상태 |
| 부족 | 주문 대비 재고 수량 부족 상태 |
| 고갈 | 수량이 0인 상태 |

---

### 3-6. 생산라인

생산라인에 대한 정보를 표시. 주문량에 대한 부족분을 생산하되, 수율 및 오차를 고려하여 시료를 생산한다.

#### 생산 수량 계산 공식

```
실 생산량 = ceil(부족분 / (수율 * 0.9))
총 생산 시간 = 평균 생산시간 * 실 생산량
```

- 생산 완료 시 주문 상태: `PRODUCING` → `CONFIRMED`으로 변경
- 스케줄링 전략: **FIFO (선입선출)**

#### 생산 현황 표기

- 현재 생산 중인 시료에 대한 정보 표기
- 표기 항목 예시: 주문 정보, 현재까지의 생산량, 진행률(%), 완료 예정 시간 등

#### 대기 주문 확인

- 생산라인의 대기열(생산 큐) 목록 출력
- 표기 항목: 순서, 주문번호, 시료, 주문량, 부족분, 실생산량, 예상 완료 시간

---

### 3-7. 출고 처리

재고가 충분해진 `CONFIRMED` 주문에 대하여 출고를 처리한다.

- `CONFIRMED` 상태의 주문 목록 표시 (주문번호, 고객, 시료, 수량)
- 특정 주문에 대해 출고를 실행
- 출고 완료 시 주문 상태: `CONFIRMED` → `RELEASE`로 전환
- 출고 결과 표시: 주문번호, 출고수량, 처리일시, 상태 변경 확인
